# العمل — تطبيق (شخصي فقط) لتتبع أجرة العمل بالساعة

تطبيق أندرويد عربي (RTL) يعمل بدون إنترنت. يسجّل أيام العمل (بداية ونهاية واستراحة) والعمل عن بعد والكريدي (يظهر بالسالب)، ويحسب الأجرة تلقائيًا من سعر الساعة.

- تسجيل دخول وخروج مع مدة مباشرة
- استلام الدفعات وأرشيفها مع ترحيل الفرق، وتعديل الدفعة والتراجع عن آخر دفعة
- ملخص ورسوم: الأجور والكريدي لكل شهر، تطور الرصيد، ساعات آخر 7 أيام، متوسط الأجر لكل يوم من الأسبوع
- بحث في الملاحظات وفلتر بالنوع (يمكن إيقافه من الإعدادات)، وتصدير السجلات CSV
- مشاركة كشوف منسقة لواتساب
- رمز قفل من 4 أرقام مع تأخير بعد المحاولات الخاطئة، وفتح بالبصمة كاختصار (من الإعدادات)
- ودجت للشاشة الرئيسية: ضغطة واحدة لتسجيل الدخول وأخرى للخروج، ويُسجَّل اليوم تلقائيًا عند فتح التطبيق
- نسخ احتياطي تلقائي (مع آخر 3 نسخ سابقة) إلى `Documents/EarningsBackup` أو مجلد تختاره، مع تشفير اختياري
- وضع فاتح/داكن تلقائي، ولون قابل للاختيار
- يستهدف Android 16، معمارية arm64 فقط
