# أرباحي — تطبيق تتبع الأرباح

تطبيق عربي بسيط لتسجيل أيام العمل (التاريخ، المدة) والكريدي (يظهر بالسالب) مع المجموع الكامل وملخص شهري.

- الأجرة تُحسب تلقائيًا من مدة العمل
- يعمل بدون إنترنت، والبيانات محفوظة على الجهاز
- نسخ احتياطي إلى `Documents/EarningsBackup` في ذاكرة الجهاز
- وضع فاتح/داكن تلقائي حسب النظام
- يستهدف Android 16، معمارية arm64 فقط

## بناء ملف APK
1. ارفع هذه الملفات إلى مستودع GitHub.
2. افتح **Actions** ← **Build APK** ← **Run workflow** (يدوي فقط).
3. نزّل `earnings-apk-arm64` من Artifacts، وفك الضغط، وثبّت `app-debug.apk`.
